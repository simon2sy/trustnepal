# GlobalTrade - Premium Import/Export Website

A world-class, premium business website for import/export and supplier companies. Built with modern web technologies and best practices.

## 🌟 Features

- **Premium Design**: Elegant glassmorphism UI with smooth gradients
- **Fully Responsive**: Mobile-first design that works on all devices
- **Smooth Animations**: Scroll-triggered animations and micro-interactions
- **Three.js Background**: Interactive particle background effect
- **Modern Components**: All essential business website components
- **SEO Optimized**: Semantic HTML and proper meta tags
- **Performance Focused**: Lazy loading, optimized assets, and efficient code
- **Accessible**: WCAG compliant with proper ARIA labels
